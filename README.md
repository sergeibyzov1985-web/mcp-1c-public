# Контур доработок 1С

Учебный пример: своё расширение к типовой программе, сценарии и проверка «можно ли отдавать».

Типовую программу этот набор не меняет. Код доработки лежит в `extensions/КонтурДоработки`, у объектов префикс `кд_`. Модульные тесты лежат в `extensions/КонтурТесты`, у них префикс `кт_`. Сценарии — папки в `features`. Новая папка со сценарием подхватывается сама, имя одного теста в запуске не зашито.

`scripts/verdict.py` программу 1С не запускает. Он читает три уже готовых файла и пишет `report.md`:

- `changes.patch` — список изменённых файлов
- `bsl.json` — отчёт проверки синтаксиса, поле `errors` или `diagnostics`
- jUnit — отчёт сценария, файл или папка

Фраза «можно отдавать» появляется только если типовая программа не задета, синтаксис чистый и названный сценарий зелёный. Иначе будет «нельзя» или «не проверено».

```text
python scripts/verdict.py --patch changes.patch --bsl bsl.json --junit report.xml --scenario очередь --out report.md
```

`scripts/check_metadata.py` тоже не запускает 1С. Он смотрит выгрузку расширения: префикс на месте, в синониме префикса нет, реквизит без своего префикса, объект входит в подсистему, список справочника открывается сценарием.

Скрипты стенда, базы, файлы поставки и чужие инструменты в этот снимок не входят.
